# ADR 0003: Consume the VM action directly

Date: 2026-10-28

Status: Accepted. Supersedes the public workflow wrapper in
[ADR 0002](0002-action-owned-vm-lifecycle.md).

## Decision

Expose `actions/vm-e2e` as the public VM validation interface. Consumers check out
their repository and invoke the pinned action in a job with the required runner,
permissions and timeout. Local Make derives its shared revision from that action
reference. VM setup, execution, reports and cleanup stay inside the action.

Remove `vm-e2e.yml` and its generated reference. The wrapper only forwarded
inputs and supplied job settings; it added a second interface without additional
validation logic. Keep success and failure scenarios in the internal action-test
workflow, which is required by shared CI.

## Consequences

Consumers can place the action alongside their other steps. They own ordinary
job settings; the implementation and lifecycle guarantees remain centralized.
Action metadata is the only public reference generated by `make docs`.

## Responsibility split

The combined action boundary is superseded by [ADR 0004](0004-focused-vm-actions.md).
