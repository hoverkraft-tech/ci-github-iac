## Overview

Create a Lima VM, execute guest assertions, publish sanitized reports and destroy the VM.

Run a consumer Bash script inside a disposable Lima VM. The action owns setup,
reports and verified cleanup, including after startup or assertion failures.
See [the usage guide](../../docs/usage/vm-e2e.md) for configuration and local runs.

<!-- overview:end -->

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-iac/actions/vm-e2e@0167859255277cc4b4010a42e5a9abc483be55da # feat/phase-1-bootstrap
  with:
    # Bash script in the checkout to execute inside the guest; a nonzero exit fails validation.
    # This input is required.
    test-script: ""

    # Optional Lima YAML file in the checkout; defaults to the bundled pinned Ubuntu image. Plain mode is enforced.
    vm-config: ""

    # Relative directory for generated e2e.junit.xml and vm.json reports.
    # Default: `.reports`
    artifact-path: .reports

    # Guest script timeout, from 1 to 40 minutes; cleanup has a separate allowance.
    # Default: `10`
    test-timeout-minutes: "10"
```
